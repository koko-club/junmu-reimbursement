# 回收站导航选中态修复设计

## 目标

用户进入 `/trash` 后，侧边栏的“回收站”应与“填写报销”和“报销记录”的当前页状态一致：黑色背景、白色文字与图标，且只有当前页入口处于选中状态。

## 根因

`static/history.js` 在回收站页使用 `toggleAttribute('aria-current', true)`，生成空值 `aria-current=""`。组件样式仅匹配 `aria-current="page"`，因此回收站入口无法获得黑色选中态，同时该空值也没有表达正确的 ARIA 当前页语义。

## 实现

- 保留现有页面结构和 CSS 选中态规则。
- 在历史/回收站共用脚本中，对当前 scope 的导航入口设置 `aria-current="page"`，并从其他入口移除 `aria-current`。
- 不改动路由、数据请求、回收站操作或其他视觉样式。

## 验证

- 先增加失败的前端契约测试，要求脚本为匹配入口设置精确的 `page` 值，并清除非匹配入口。
- 实现最小修复后，运行前端契约测试和相关语法检查。
- 在桌面和窄屏视口实际打开 `/history` 与 `/trash`，确认当前入口为黑色，其余入口为白色，且布局无重叠。
