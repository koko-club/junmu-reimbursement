# 日期控件视觉与交互设计

## 范围

为填写报销页的 12 个 `input[type="date"]`（顶部报销日期和 11 个行程明细日期）增加统一的自定义日历弹层。真实日期输入、字段名、ISO `YYYY-MM-DD` 提交值和后端接口保持不变。

## 视觉

- 弹层挂载到 `body`，使用固定定位，避免被明细表的横向滚动容器裁切。
- 表面沿用现有 UI 令牌：半透明白色、低对比边线、`--ui-radius-md` 圆角和 `--ui-shadow-lg` 阴影。
- 顶部显示中文年月和左右月份按钮；星期标题使用低对比灰色。
- 日期网格固定 7 列，当前月外日期降级显示。
- 已选日期使用 `#1d1d1f` 实心圆和白色文字；未选日期悬停使用浅蓝灰圆底；今天但未选中使用细雾蓝描边。
- 遵守 `prefers-reduced-motion` 和 `prefers-reduced-transparency`。

## 行为

- 点击或键盘聚焦日期输入后打开共用弹层；空值默认显示今天所在月份。
- 支持上/下月、选择日期、回到今天、Esc 关闭、点击外部关闭，以及方向键移动和 Enter/Space 确认。
- 选择后仅写回真实输入的 ISO 值并派发 `input`/`change` 事件，现有 `.has-value` 显隐逻辑继续生效。
- 表单重置时关闭弹层并清空镜像状态；关闭后恢复触发输入的焦点。
- 自定义脚本不可用时保留原生日期输入作为兜底。

## 实现边界

- 新增独立 `calendar.js` 和 `calendar.css`，不引入第三方依赖。
- 不修改生成接口、服务端校验、Excel/PDF 逻辑或现有字段结构。
- 日历算法使用整数日期计算，避免时区转换改变提交日期。

## 验证

- 增加前端契约断言，确认日历资源被加载、12 个日期字段仍保留原生类型和 ISO 回写逻辑。
- 运行现有前端/服务端契约测试。
- 启动本地服务，检查桌面和窄屏下的选中、悬停、月份切换、重置和键盘操作。
