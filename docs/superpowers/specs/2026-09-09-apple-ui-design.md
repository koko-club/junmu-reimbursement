# 报销系统 Apple 风格 UI 设计规格

## 目标

在不改变报销、认证、历史记录、回收站、管理端的核心业务代码前提下，将整个系统的视觉更新为 Apple 白色系统设置风格。

## 范围

- 认证：登录、注册、修改密码、初始设置
- 业务：报销填写、历史记录、回收站
- 管理：管理员列表、操作对话框
- 响应式：桌面、窄屏和移动端导航

## 视觉基础

- 系统字体：`-apple-system` / `BlinkMacSystemFont` / `PingFang SC`
- 背景：暖白灰和浅灰色层级，内容面板保持实色白
- 主操作色：低饱和灰蓝（取代高饱和蓝），用于主按钮、链接和导航选中状态
- 危险、成功和警告色仅用于状态反馈，不用于装饰
- 圆角以 8–12px 为主，按钮、输入框、弹窗保持稳定尺寸
- 内容面板使用轻阴影和细边界，不使用装饰性大卡片

## 交互

- 保留所有现有字段、`id`、`name`、`data-*` 属性、JS 事件和 API 请求
- 按钮在 `:active` 时使用轻微缩放反馈，动画仅使用具体属性
- 弹窗使用快速 ease-out 进入，支持减少动态模式
- 移动端导航保留现有开关行为，只更新外观

## 验证

- 运行现有前端测试与全量测试
- 确认表单提交、文件预览、历史操作和管理员操作行为不变
- 检查桌面和移动端布局、焦点状态、可读性和减少动态支持
